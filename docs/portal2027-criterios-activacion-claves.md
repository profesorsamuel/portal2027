# Condiciones antes de activar claves temporales

- [ ] Panel administrativo instalado y probado.
- [ ] Claves entregadas individualmente y sin almacenamiento permanente.
- [ ] Cuenta ficticia creada en un entorno seguro con la opción temporal habilitada solamente allí.
- [ ] Datos privados bloqueados hasta completar el cambio obligatorio.
- [ ] Inicio con contraseña nueva y rechazo de contraseña anterior comprobados.
- [ ] Recuperación individual implementada y validada, sin afectar cuentas existentes.
- [ ] Rate limits, políticas de Supabase y seguridad de Edge Functions comprobados.
- [ ] Plan de reversión y comunicación a familias aprobado.

Hasta completar todos los puntos, mantener desactivada la variable en producción.
